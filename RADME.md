# Проект: Анализ банковских операций

## Описание
Проект предназначен для анализа банковских операций с использованием excel-файла, 
запросов к интернет-источникам для получения актуальных цен акций MOEX и курсов валют

## Установка

1. Убедитесь, что у вас установлен Python версии 3.6 или выше.
2. Установите необходимые зависимости, выполнив команду:

```commandline
pip install -r requirements.txt
```
## Зависимости

• pandas

• openpyxl

• json

• requests

• logging

• config (ваш модуль конфигурации)

## Модуль views
Основной модуль для работы прогрммы. Для запуска необходимо убедиться
в наличии всех предпочитаемых настроек в модуле **config**,
а так же наличие excel-файла **data/operations.xlsx**


## Модуль utils
Этот модуль предназначен для анализа данных о банковских операциях из Excel-файла, предоставляя функции для фильтрации операций по дате, расчета сумм трат и получения кешбека по картам, а также для вывода топ-5 транзакций.

### greeting()

Функция возвращает приветственное сообщение в зависимости от времени суток, когда пользователь запускает программу.

### excel_reader()

Считывает данные из Excel-файла, конвертируя дату операции в формат DateTime.

### filter_operations(operations_df, year, month)

Фильтрует операции по заданному месяцу и году, возвращая DataFrame с отфильтрованными данными.

### cashback_categories(df)

Возвращает список словарей с суммами всех трат по каждой карте и суммой кешбека.

### top_transactions(df)

Возвращает список словарей, содержащих топ-5 операций по сумме, с указанием даты, категории и описания.


## Использование

1. Импортируйте необходимые функции в ваш скрипт.
2. Используйте excel_reader() для чтения данных из Excel.
3. Применяйте фильтрацию и анализ с помощью функций filter_operations(), cashback_categories(), и top_transactions() для получения нужных данных.

Пример:

from your_module_name import excel_reader, top_transactions

# Чтение данных
df = excel_reader()

## Получение топ-5 транзакций
top_5 = top_transactions(df)
print(top_5)

## Модуль api_request
Этот модуль позволяет получать курсы валют от Центрального банка России и цены акций с сайта Московской биржи. Данные о курсах валют и акциях настраиваются пользователем через файл конфигурации.

### settings_reader() -> dict[list]

Функция для чтения пользовательских настроек из файла конфигурации. Возвращает словарь с настройками.

### get_currency_rate(codes: list) -> Generator[dict]

Получает курсы валют, настроенные пользователем, с сайта ЦБ РФ.

Параметры:

codes: список кодов валют, которые необходимо получить.

Возвращает:

Генератор, выдающий словари с кодом валюты и её курсом.
#### Пример использования

from your_module_name import settings_reader, get_currency_rate, get_currency_stocks

#Чтение настроек пользователя
settings = settings_reader()

#Получение курсов валют
```currency_rates = get_currency_rate(settings['user_currencies'])
for rate in currency_rates:
    print(rate)
```
#Получение цен акций
```
stock_prices = get_currency_stocks(settings['user_stocks'])
for price in stock_prices:
    print(price)
```

## Модуль services
Сервис позволяет проанализировать, какие категории были наиболее выгодными для выбора в качестве категорий повышенного кешбэка.

### cashback_categories(df: pd.DataFrame) -> str

Возвращает сумму всех операций по категориям в формате JSON для последующего анализа выгодности кешбека.


### Использование
1. Запустите скрипт и следуйте инструкциям для ввода года и месяца.
2. Программа считает данные из Excel-файла, отфильтровывает операции по заданным параметрам и выводит суммы по категориям в формате JSON.

#### Пример использования

```
if __name__ == "__main__":
    while True:
        input_year = input("Введите год: ")
        if 0 < int(input_year) < 9999:
            print(f"Получение данных за {input_year} год")
            break
        else:
            print("Недопустимый ввод")

    while True:
        input_month = input("Введите месяц: ")
        if 1 <= int(input_month) <= 12:
            print(f"Получение данных за {input_month} месяц")
            break
        else:
            print("Недопустимый ввод")

    ex = excel_reader()
    fil = filter_operations(ex, int(input_year), int(input_month))

    operations_summ = cashback_categories(fil)
    print(operations_summ)
```

## Модуль reports
Модуль логгирования. Возвращает траты по заданной категории за последние три месяца (от переданной даты).
### search(data_for_search: str) -> str

Функция поиска в DataFrame по ключевому слову в столбце "Категория" или "Описание". Возвращает JSON-строку с найденными записями.

Параметры:

data_for_search: строка, по которой будет осуществляться поиск.

Возвращает:

JSON-строка с найденными записями.


Все операции логируются и сохраняются в файл services.log, который создается в директории, указанной в PATH_TO_LOGGER.
Логирование включает уровни DEBUG и INFO.


#### Пример использования:

from your_module_name import search

*Поиск по ключевому слову "Дом и ремонт"*

result = search("Дом и ремонт")
print(result)
